# jiaolong AI 助手框架 — Briefing

> **一句话描述**: 让 AI 助手拥有记忆、会学习、能自我进化的增强框架

---

## 解决的问题

| 痛点 | jiaolong的解决方案 |
|------|-------------|
| AI每次对话都要重新介绍背景 | **语义记忆召回** — 自动理解上下文 |
| 代码质量靠人工review | **clean-code规则引擎** — 写代码自动检查 |
| 重复问题要反复回答 | **Skills自动触发** — 关键词即触发 |
| 外部报告需要逐项验证 | **博弈审查** — 对抗性代码审查 |

```
之前：AI是"无记忆的工具"

```

---

## 三大核心能力

### 1. 记忆层 (v6.0+ 原生集成)
- **原生记忆**: 使用 Claude Code 原生 `.md` 记忆系统
- **语义召回**: 不用精确关键词，模糊描述也能找到记忆
- **自动提取**: 对话结束自动提取有价值的信息
- **每次对话注入**: 无需手动@recall，AI自动带着上下文

### 2. 自动化层
- **Skills 自动触发**: 说"帮我选股"就执行选股，不用记命令
- **并行执行**: 3个任务同时跑，耗时从3秒→1.2秒
- **博弈审查**: 对抗性代码审查，逐项验证外部报告

### 3. 质量层
- **8条 clean-code 规则**: 空stub/魔法数字/函数过长等自动检测
- **100 测试覆盖**: 核心模块行为测试，非 trivial 断言
- **端到端验证**: 记忆写入→召回→注入完整链路
